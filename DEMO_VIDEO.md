# Demo Video

This project includes a live demo walkthrough and prototype presentation footage for the MeshLink / ResQ-Mesh system.

## Live Demo Link

[Open Demo Drive Folder](https://drive.google.com/drive/folders/1hMYj4an9CNFQo3l9NkYhKNwZxiXUK4es?usp=sharing)

## What to show in the demo

- Offline emergency communication concept
- Multi-phone mesh relay flow
- Store-and-forward message propagation
- Local device discovery in disconnected conditions
- Emergency broadcast / SOS concept
- Command dashboard overview for rescue operations

## Recommended demo script

1. Open the mobile app on three Android phones.
2. Keep them close together in airplane mode with Bluetooth enabled.
3. Trigger an emergency message from the sender phone.
4. Show the message being relayed through the intermediate node.
5. Show the final recipient receiving the SOS or alert.
6. Explain the off-grid mesh architecture and rescue use case.

## Presentation idea

> When normal cellular infrastructure fails, nearby phones can still communicate locally through a resilient mesh network. This makes emergency messaging possible even in blackout or disaster scenarios.

## Notes

- Use the app in a short-range local setup for clean demonstration.
- Keep the phones near each other during the demo.
- Use the dashboard as a visual explanation layer for judges or viewers.
